САЙТ-ВИЗИТКА — ИНСТРУКЦИЯ

1. Откройте index.html в браузере для локального просмотра.
2. Для публикации загрузите ВСЕ файлы и папку assets на хостинг, сохранив структуру.
3. Замените демонстрационные фотографии в index.html на фотографии своих объектов. Сейчас изображения загружаются с images.unsplash.com и требуют интернет-соединения.
4. Замените название «МАСТЕР» на ваше название, если нужно.
5. Форма заявки открывает WhatsApp на номер +7 914 549-05-00 с заполненным текстом. Пользователь должен нажать «Отправить» в WhatsApp. Заявки не сохраняются на сервере.
6. Кнопки WhatsApp и Telegram настроены на указанные номера. Telegram-ссылка по номеру может работать только если номер доступен для поиска/связи в настройках Telegram; для надёжности можно заменить её на ваш публичный @username.
7. Номера указаны в международном формате +7, исходя из российских номеров, начинающихся с 8.

Для реального серверного хранения заявок понадобится backend или интеграция с CRM/ботом.
